# Project Context: Spring AI Infinispan

This project provides Spring AI integrations for Infinispan: a vector store for similarity search and a chat memory repository for conversation persistence.

## Shared guidelines
- Use the project's established patterns and terminology. Follow the conventions of the module you are working in.
- Prefer clarity over cleverness. This is a long-lived open-source project with many contributors.
- Each module is independently versioned and self-contained — the root POM is an aggregator, not a parent.

## Testing instructions
