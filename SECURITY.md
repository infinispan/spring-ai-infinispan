# Security Policy

The Infinispan team and community take all security bugs very seriously.

## Reporting Security Issues

If you think you have found a security vulnerability, please report it to:

- **Email:** security@infinispan.org
- **Red Hat Product Security:** https://access.redhat.com/security/team/contact/

You may encrypt your report using the [Red Hat Product Security PGP key](https://access.redhat.com/security/team/key/).

Please do **not** report security vulnerabilities through public GitHub issues.

## Supported Versions

This project follows Infinispan's release cycle. Security fixes are applied to the latest release.
